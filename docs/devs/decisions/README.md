# Decisions

Choices that were contested, that shaped the skills, and that
someone will eventually want to reverse. Each records what was
decided and why, so reversing it is a deliberate act rather than an
accident.

These are not a changelog. A decision belongs here when reversing it
would be reasonable-sounding but wrong for reasons that are not
obvious from the code.
